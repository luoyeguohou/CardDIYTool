# Card DIY Tool

# Usage
For boardgame designers, the tool can help them make their cards instead of photoshop those cards one by one. They can customize the image size such as A4 size which is eazy to print.

For card video game developpers, with tabletopsimulator, they can test their game very easily without coding.

# What you need
What you need to do is:

     1. Prepare image resources.

     2. Prepare a json file which has all data.

     3. Use this tool to create card and export the image you need.
